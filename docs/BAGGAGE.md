# Baggage sites vs PAX checkpoints

Baggage is not a checkpoint with a different label. CBRA, OS, and OSRA are their own site kind.

Builder publishes physical rooms and units (seats). Demand module publishes which units are open by slice and manual peak FTE raises.

OSRA is optional infrastructure: present true/false. Do not delete the record.

Alpha today only has poolBag on TSO lines. That is people eligibility, not a place. Keep both.
